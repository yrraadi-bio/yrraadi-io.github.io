Introducing Sibyl

June 2026

Highlights

  • Sibyl predicts spatial transcriptomics from H&E at single-cell resolution across diverse tissues.
  • Built on a unified architecture that predicts cellular layout from H&E patch embeddings, then uses that inferred layout to assign per-cell gene expression.

Today, we are introducing Sibyl, a single-cell resolution H&E to spatial transcriptomics model. Sibyl is designed to make molecular state accessible from ordinary histology while preserving the native cell-level spatial organization of the tissue. At inference time, Sibyl only needs H&E patch embeddings: it predicts the cellular layout within the patch, then uses that layout to return molecular predictions assigned to specific cells and spatial positions.

Spatial transcriptomics is powerful because it ties gene expression back to tissue architecture. That has obvious clinical relevance: spatial assays are already being used to study tumor microenvironments, immune niches, diagnostic biomarkers, and therapy-response programs in intact tissue [1], [2]. The challenge is scale. Most spatial assays are still expensive, sparse, and difficult to run across the same sample sizes as H&E. Sibyl is built around the opposite constraint: H&E is abundant, cheap, and already embedded in pathology workflows. If a model can learn a robust mapping from morphology to expression across tissue types, it can make transcriptomic readouts available wherever high-quality histology already exists.

Several groups have already shown that histology can predict spatial expression. ST-Net, HisToGene, and Hist2ST learn spot-level mappings [3], [4], [5], so their predictions inherit the resolution limit of the assay: one spot-level target can average multiple cells and erase the cell-to-cell variation that matters biologically. Newer single-cell methods get closer, but still depend on external cell geometry. GHIST segments H&E nuclei with HoVer-Net, segments Xenium/DAPI/transcripts with BIDCell, then matches the two nuclei sets by overlap; any mismatch between those objects becomes supervision noise [6]. DeepCell is trained around Xenium cell coordinates and crops a centered H&E tile for each supplied cell [7]. In an H&E-only setting, that means adding an upstream DAPI-like cell-localization or segmentation model before expression prediction, which makes the workflow less direct and less flexible. Sibyl predicts the cellular layout from patch embeddings and uses that inferred layout for per-cell expression in one model.

Spearman correlation asks whether Sibyl recovers the ordering of ground-truth cells for each gene: cells with higher measured expression should also receive higher predicted expression. Because each cell has a spatial coordinate, good cell-level ranking translates into recovering where gene expression is high or low across the tissue. But not all genes behave the same way: some are diffuse and close to randomly spread across the slide, while others organize into coherent neighborhoods, compartments, or cell-state regions that morphology can actually explain. Moran’s I captures this by measuring spatial autocorrelation, separating the genes whose structure is recoverable from histology from those that are not. Together, these metrics test whether Sibyl learns both which cells should express a gene more strongly and whether that expression forms the right spatial structure.

Aggregate correlations are useful, but spatial biology ultimately has to be visible. To see this directly, we look at three canonical lineage markers across two different tissues, breast and pancreas, on held-out patient slides. Each gene labels a distinct compartment: EPCAM is an epithelial adhesion molecule that marks epithelial and tumor cells, PDGFRA is a receptor expressed by stromal fibroblasts, and PTPRC, also known as CD45, marks immune cells. Because these genes track separate cell populations, their spatial maps should look distinct, and the model should place each in the right neighborhoods rather than smear expression uniformly across the slide. In both tissues, Sibyl recovers this compartment structure from H&E alone: EPCAM lights up the epithelial and tumor regions, PDGFRA traces the surrounding stroma, and PTPRC picks out immune-infiltrated areas, with the predicted maps following the same spatial layout as the measured ground truth.

Architecture and Data

Sibyl uses a frozen H&E image encoder to convert each tissue patch into visual tokens, followed by a shared transformer trunk that integrates morphology across the patch. From this shared representation, the model branches into three heads: a per-cell expression head, a detector head that predicts the probability that each target gene is non-zero in a given cell, and a density head that predicts where cells lie within the patch.

The central design decision is that cells enter the model as queries defined by their own centroids. Each cell's relative position inside the patch is encoded with a Fourier embedding and used as a query that cross-attends to the patch's image tokens, producing a feature for that specific cell. This is what lets Sibyl avoid object mismatch. Single-cell approaches like GHIST detect nuclei on the H&E with a separate model such as HoVer-Net and then match those detections against the transcriptomics segmentation, so any disagreement between the two sets becomes label noise. Sibyl has no matching step: the cell centroids are themselves the queries, so every prediction is anchored to a real cell rather than to the overlap between two independent segmentations.

The density head then predicts where cells are likely to be inside the patch. During training the cell queries are placed at the true centroids, but the density head learns the cellular layout so that at inference Sibyl does not need externally provided cell coordinates, such as Xenium centroids or an upstream nucleus detector. It can predict the layout itself and then query expression at those inferred positions, keeping the whole pipeline driven by H&E alone.

The detector head exists to handle a quirk of the training objective. Because the expression head is trained with MSE on log1p counts, true zeros are never pushed all the way down; the model assigns them a small non-zero value, which shows up as faint background in the marker maps above where no gating is applied. The detector head independently predicts the probability that each gene is non-zero in a cell, and gating expression by this probability suppresses those spurious low values.
